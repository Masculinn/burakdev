# burakdev

![A snapshot of my personal app](/public/assets/pwa/burakdev-desktop-screenshot.png)

My personal web app for blogging and portfolio. Built at the top of latest traditional Typescript, React, Next.js, Node.js, shadcn/ui, TailwindCSS and Supabase on the backend with a pendulum.

### Latest Specs:

- **Type Safety**: [Typescript](https://www.typescriptlang.org/)
- **Framework**: [Next.js(pages router)](https://nextjs.org/)
- **UI Framework**: [React](https://react.dev/)
- **Scripting**: [Node.JS](https://nodejs.org/)
- **Design System**: [Shadcn](https://ui.shadcn.com/)
- **Styling/CSS**: [TailwindCSS](https://tailwindcss.com/)
- **Rendering Strategy**: [Static Generation(SSG)](https://nextjs.org/docs/basic-features/data-fetching/get-static-props)
- **Database**: [Supabase/Postgres](https://supabase.com/)
- **Deployment/Hosting**: [Netlify](https://www.netlify.com/)
- **CI/CD**: [Netlify](https://www.netlify.com/)
- **Animation**: [Motion Provider](https://motionprovider.dev/)
- **CDN**: [Imgix](https://imgix.com/)
- **Image processing**: [Sharp](https://sharp.pixelplumbing.com/)
- **Analytics**: [GA](https://analytics.google.com/)
- **Linter**: [Biome](https://biomejs.dev/)
- **Formatter**: [Prettier](https://prettier.io/)
